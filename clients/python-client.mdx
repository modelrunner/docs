## Overview

ModelRunner provides a unified Python SDK to call any supported model with a consistent interface. Use it in scripts, services, and notebooks with both async and sync workflows.

<Callout>
For scripts and notebooks, never hardcode secrets. Use environment variables to manage your key securely.
</Callout>

## Installation

<CodeGroup>

```bash pip
pip install modelrunner-ai
```

```bash pip3
pip3 install modelrunner-ai
```

```bash poetry
poetry add modelrunner-ai
```

</CodeGroup>

## Configure credentials

Configure the client with a single key. Environment variables are recommended.

```bash
export MODELRUNNER_KEY=your-api-key
```

<Tip>
Get your credentials from your ModelRunner account. Keep them server-only and out of version control.
</Tip>


## Call a model

The client offers both synchronous and asynchronous APIs. Pick whichever fits your codebase — they call the same underlying endpoints.

### Sync — `run()`

`run()` blocks until the request reaches a terminal state and returns the final result. Ideal for scripts, notebooks, and one-shot CLI tools.

```python
import modelrunner_ai

result = modelrunner_ai.run(
    "bytedance/sdxl-lightning-4step",
    arguments={"prompt": "two friends cooking together"},
)
print(result["output"])
```

### Async — `submit_async()` + `iter_events()`

`submit_async()` returns immediately with a response handle. Iterate `response.iter_events()` to react to each status transition, then `await response.get()` for the final output. Best for servers, queue workers, and any code that needs to surface intermediate progress.

```python
import asyncio
import modelrunner_ai

async def main():
    response = await modelrunner_ai.submit_async(
        "bytedance/sdxl-lightning-4step",
        arguments={"prompt": "two friends cooking together"}
    )

    logs_index = 0
    async for event in response.iter_events(with_logs=True):
        if isinstance(event, modelrunner_ai.Queued):
            print("Queued.")
        elif isinstance(event, (modelrunner_ai.InProgress, modelrunner_ai.Completed)):
            new_logs = event.logs[logs_index:]
            for log in new_logs:
                print(log["message"])
            logs_index = len(event.logs)

    result = await response.get()
    print(result["output"])

asyncio.run(main())
```

### Event types

`iter_events()` yields one event per status transition:

| Event         | When it fires                                                    | Has `logs`? |
| ------------- | ---------------------------------------------------------------- | ----------- |
| `Queued`      | Request accepted, waiting for the provider.                      | no          |
| `InProgress`  | Provider is generating output.                                   | yes         |
| `Completed`   | Terminal — output available on the response handle.              | yes         |
| `Failed`      | Terminal — provider error or force-failed. Not billed.           | yes         |

### Cancelling a request

Every async response handle exposes the underlying `cancel_url`. Issue a GET to it from your HTTP client of choice:

```python
import httpx
import os

httpx.get(
    response.cancel_url,
    headers={"Authorization": f"Key {os.environ['MODELRUNNER_KEY']}"},
)
```

Cancellation is immediate if the provider hasn't started; best-effort otherwise. See [request lifecycle](/guides/request-lifecycle#cancellation).

## Upload files

Upload local files to ModelRunner storage and receive a temporary URL you can pass to model inputs (for example, image or audio URLs).

<CodeGroup>

```python Python
import modelrunner_ai

input_image = modelrunner_ai.upload_file("./image.jpg")
print(input_image)
response = modelrunner_ai.run("swook/inspyrenet", arguments={"image_path": input_image})
print(response["output"])
```

</CodeGroup>
