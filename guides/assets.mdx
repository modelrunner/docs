## Overview

Every file that passes through ModelRunner becomes a tracked **asset** in your library — automatically, with nothing to set up:

- **Uploads** — any file you upload as a model input (see [File uploads](/guides/file-uploads)).
- **Outputs** — every image, video, or audio file a model run generates.
- **External inputs** — file URLs you pass straight to a model input.

The library is one place to find, organize, and reuse those files. Its biggest payoff: a model's output drops straight into your next run as an input — no re-downloading, no re-uploading.

<Note>
  The asset library is a dashboard feature. Find it under **Settings → Assets** in the [ModelRunner dashboard](https://modelrunner.ai). Assets are private to your account.
</Note>

## Browsing your assets

Open **Settings → Assets** to see everything you've generated or uploaded, newest first. Switch between two layouts:

- **Grid** — thumbnail previews for images and video, file-type icons for everything else.
- **Table** — filename, source, type, size, and creation date in columns.

Narrow the list with filters and search:

| Control | Options |
| --- | --- |
| **Source** | All · Outputs (generated by a model run) · Uploads (files you uploaded) |
| **Type** | All · Images · Videos · Other files |
| **Search** | Match against the filename |

Click any asset to open its detail view.

## Asset details

The detail panel shows everything about a single file:

- A **full-size preview** for images and video, or a file-type icon for other formats.
- **Metadata** — source, MIME type, file size, and when it was created.
- **Linked requests** — the request(s) that produced or consumed the file, so you can trace any asset back to the run it came from.
- **Copy URL** — copy the canonical `media.modelrunner.ai` URL to reuse or share.
- **Download** — save the original file.

<Tip>
  Every asset has a stable `media.modelrunner.ai` URL. Copy it and pass it to any model input field that accepts a file — it behaves exactly like an [uploaded file URL](/guides/file-uploads).
</Tip>

## Favorites and tags

Keep a growing library tidy so the files you reach for most stay close:

- **Favorites** — star any asset, then filter the library to favorites only.
- **Tags** — apply your own labels and filter by them. Create a tag on the fly while tagging an asset. Combine several tags with **any** (match any selected tag) or **all** (match every selected tag).

## Reusing an asset as a model input

The library is wired into every file input field, so you rarely upload the same file twice. When a model asks for a file, the input offers three sources — **Upload**, **Enter URL**, and **Search assets**:

<Steps>
  <Step title="Open the asset picker">
    On any file input, choose **Search assets**.
  </Step>
  <Step title="Find the file">
    Search by name, or filter by bucket (all media, favorites, uploads), type, and tags. The picker pre-filters to the type the field expects — an image field shows images.
  </Step>
  <Step title="Select and run">
    Pick the asset (one or several, depending on the field). Its URL is filled into the input. Submit the run as usual.
  </Step>
</Steps>

This is what makes a multi-step pipeline painless: generate an image with one model, then feed that exact output into an upscaler or a video model without ever leaving the browser.
